# Roadmap (12 weeks / 6 sprints)

1. **Wk 1-2** Setup, CI, database, FR-01/02 (auth), first Figma screens, request historical data
2. **Wk 3-4** FR-03..FR-09 (browse, booking + QR, notifications, history)
3. **Wk 5-6** FR-10..FR-16 (organizer module), data cleaning + features
4. **Wk 7-8** FR-17..FR-22 (admin), descriptive analytics, train attendance model, early production deploy
5. **Wk 9-10** FR-23 (AI assistant), analytics dashboard + prediction, security hardening, load test (500 users)
6. **Wk 11-12** E2E tests, bug fixing, final docs, demo rehearsal

Foundation is "done" when register -> login -> protected page works end to end. Tag it `foundation-v1`, then everyone starts their module.
